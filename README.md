# Charisiss

Personal portfolio for [Charisis Samaras](https://charisiss.gr) — Next.js, Tailwind CSS, Framer Motion, and a React Three Fiber hero scene.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — portfolio
- `/meet` — booking calendar
- `/linktree` — social / quick links
